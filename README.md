# PlaylistMaker 🎧

Приложение для поиска, прослушивания треков и создания собственных плейлистов на основе API iTunes.

## Функциональность

- Поиск и прослушивание музыки через API iTunes
- Добавление треков в избранное
- История последних 10 прослушанных композиций
- Создание плейлистов с обложкой и описанием
- Возможность делиться плейлистами с друзьями
